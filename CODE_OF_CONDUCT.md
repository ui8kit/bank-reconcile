# Code of Conduct

## Commitment

Bank reconcile (UI8Kit) is a small open-source tool for matching bank statements
in the browser. Contributors and users deserve a professional, inclusive project
space.

## Expected

- Clear, respectful technical discussion
- Assume good intent; disagree on ideas, not people
- Give and take concrete feedback (repro steps, sample files, browser/OS)
- Credit others’ work (ui8kit, pdf.js, fonts, upstream fixtures)

## Unacceptable

- Harassment, discrimination, or personal attacks
- Publishing others’ secrets, personal bank data, or exploit details without
  coordinated disclosure
- Spam, off-topic promotion, or bad-faith disruption of issues/PRs
- Dumping real customer statements into public issues without redaction

## Scope

Applies to GitHub (issues, PRs, discussions, security reports) and any official
channels representing this repository ([ui8kit/bank-reconcile](https://github.com/ui8kit/bank-reconcile)).

## Enforcement

Maintainers may warn, restrict, or ban accounts that violate this code. Report
privately to the maintainers (or via [SECURITY.md](SECURITY.md) when the report
is a vulnerability).
